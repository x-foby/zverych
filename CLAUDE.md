# Telegram-бот — участник сообщества (Go)

Перед любой работой прочитай:
1. `SPEC.md` — ТЗ и источник истины по требованиям и принятым решениям;
2. `STATUS.md` — где остановились: что не закоммичено, как запустить локально, следующие шаги.

- Если решение меняется — обнови `SPEC.md` (соответствующий раздел и «Журнал решений»), отметь прогресс в «Этапах».
- В конце сессии обнови `STATUS.md`.
- Открытые вопросы перечислены в разделе 13 `SPEC.md`.
- Секреты только в `.env`, никогда не коммитить. `config.yaml` и `persona.md` тоже в .gitignore; шаблоны — `config.example.yaml` и `persona.example.md`.
- Коммитить и пушить — только по явной просьбе владельца.
- Проверка: `gofmt -l . && go vet ./... && gopls check $(git ls-files -co --exclude-standard '*.go') && go test -race ./...` (`gopls check` — те же замечания, что показывает VS Code; вывод должен быть пустым).
